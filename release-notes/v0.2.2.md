# 酷DO 0.2.2

## 新增

- 话题前台自动加载新回复并保留阅读位置，显示正在回复的用户头像。
- 楼中楼支持图片摘要和画廊查看，图片保存菜单显示原图与批量预估容量。
- 首页刷新提示实际新增内容数，没有新内容时不显示提示。
- 支持 Obsidian Callout、表格、引用、目录导航、有序嵌套列表和清单状态。
- 支持 BBCode 彩色文字、上标脚注及液态阅读弹窗。
- 楼层选择改为可展开的黄色液态滑块，支持连续拖动、手动输入和未修改时直接关闭。
- 置顶帖默认精简单行显示，用户签名默认开启；显示设置可调整相关选项。
- 应用内 Toast 统一为黄色背景、黑色文字样式。

## 修复

- 补齐列表封面、全屏图片和相册的加载失败提示、重试和 SVG 图片解码。
- 修复深色模式网页加载时标题栏和状态栏闪白，以及短话题滚动到底后的楼层计数。
- 修复楼层少时液态滑块的台阶移动，并消除展开、收回动画末尾的布局跳变。
- 完善我的页面吸顶身份渐显和访客、个人中心的设置入口。
