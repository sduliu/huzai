# 虎Do 0.2.5

## 修复

- 首页频道滑动更顺：频道落定后自动预取左右相邻频道数据，滑过去即有内容
- 比赛卡片对齐官方样式：赛事名 + 队徽 + 大比分，进行中/开赛时间/评分人数一目了然
- 点帖子和评论区头像可以直接进入 TA 的用户主页，未登录也能查看（资料卡、发帖、回帖列表完整显示）
- 评论区表情和贴图不再占满整行：缩小为紧凑尺寸展示，点击仍可看大图
- 「比赛」页默认频道与第一栏保持一致，不再默认热门赛事
- 板块资讯列表的亮数/回复数改为纯文字展示，标题字号对齐官方
