# 虎Do 0.2.8

## 新增

- 赛事频道对齐官方：比赛大卡下方新增圆形快捷图标行（赛程 / 积分榜），资讯区支持「推荐 / 最新」切换
- 版块页对齐官方：新增版块档案头（队标 + 名称 + 帖子数 + 简介 + 关注按钮）、平铺帖行（作者 + 标题 + 回复/推荐 + 时间）和红色「立即发布」按钮
- 热榜频道新增「评分榜」：横滑主题评分卡片，点击进入虎扑评分频道
- 「查看全部赛程 / 热门比赛 / 比赛卡 / 积分榜」改为二级页打开，可返回、不再跳转底栏

## 调整

- 赛程中心改为官方式日期分组紧凑赛程行（时间 + 赛事 | 队徽队名比分 | 状态/评分人数）
