# Agent Note: 批X11 数据中心四 tab 剩余差异修复（顶部遮挡/左栏/列合并/长名）

Status: implemented

## Problem

批X8 有条件通过后 Muse 2026-10-27 真机实测（测试包 2048）残留五项：①四 tab 顶部内容（赛季下拉/分组列头/首行）被浮空顶栏+数据 tab 轨道遮盖；②选秀左栏（第一轮/第二轮）真机 dump/截图双确认未渲染；③左栏分类名换行/截断（西部排/行、前场篮/板、凯尔特…）；④球队榜胜率与胜场差仍两列，官方一格「75.0%/0.5」；⑤选秀外援长名与四字队名省略。

## Root causes

- **顶部遮挡**：`ScorePage` 浮空顶栏布局中内容层从 y=0 起画，宿主把测量出的顶栏+轨道高度以 `topInset` 参数传入 `DataTabContent`，但旧实现只把 `topInset` 转给 `GlobalScheduleView`，四个原生数据页（Standings/PlayerRank/Draft/Injury 等）直接裸画在 y=0 → 顶部被遮。赛程页不受影响因其自行消费 inset。
- **选秀左栏未渲染**：X8-3 代码确有左栏（Row+LazyColumn width 84），官方 URL `/300003/nba/draft.html` 实测匹配 `nativeDataTabKind`（非 H5 embed）。真机 dump 无左栏的确切根因无法本地复现确认，最可能：顶栏遮挡 + 滚动定位式交互下左栏与列表同色弱存在感，或当时安装的是 X8 前旧包。X11 顺带重建为点选换数据的官方语义。
- **左栏换行**：84dp 栏 - 栏内边距 16 - 项内边距 20 = 48dp 文字区；「西部排行」4 字@13sp=52dp、「球队技术犯规」6 字=78dp → 换行/截断。
- **长名省略**：选秀行固定位 182dp（顺位24+头像30+间距8+球队48+数据72），360dp 屏姓名区仅 ~78dp；球队榜四字队名列 ~52dp 恰好贴线。

## Decision

- **X11-1 顶距**：`DataTabContent` 原生页分支统一包 `Box(Modifier.fillMaxSize().padding(top = topInset))`——消费宿主测量值而非硬编码；`GlobalScheduleView` 已自用 inset 不重复加；浮空模式关闭时 topInset=0。
- **X11-2 选秀左栏**：重建为点选切换语义（`roundSel` 过滤单轮表），默认第一轮；年份切换后 `roundSel` 失效自动回第一轮。与 X8 滚动定位式的差别：官方口径「切换轮次换数据」是互斥展示非滚动锚定。
- **X11-3 左栏**：96dp + 项字号 12sp + 项水平边距 8 + 栏边距 4 + maxLines=1 → 文字区 72dp，恰容 6 字分类单行；选秀栏仅 3 字项反收窄至 72dp。右栏对冲：球员榜 球队40/数据40，伤病 伤停48/最新进展56。
- **X11-4 合并列**：parser 层 cells 4→3「w-l | winRate/gb | 近况」，列头「胜-负|胜率/胜场差|近况」；表宽按列头是否含「/」给 64dp/40dp。X8 备选方案中曾否决合并（彼时判断官方是四独立标签），X11 按 Muse 真机规格翻案执行——记录在此以更新旧结论。
- **X11-5 长名**：选秀行固定位 182→152dp（顺位20/头像26/间距6/球队40/数据60@10sp）→ 姓名区 ~108dp，约 8 字等宽全显；球队榜队名列 →~56dp（排名18/队标间距2）覆盖四字短名。

## Alternatives considered

- 顶距给原生页逐个内部加 padding：等价但更散、漏加风险高，统一外层包好维护。
- 左栏按最长类别动态测宽：过度工程；96dp 固定值已覆盖实测最长「球队技术犯规」6 字。
- 长名单字号再降（11sp）：可读性差于收窄固定位；未取。
- 选秀左栏滚动定位（X8 原实现）：官方语义为切换展示，翻案。

## Consequences

- 合并列后 `MatchDetailPage` 的 `columns.zip(cells)` 拼串输出变为「胜率/胜场差 75.0%/0.5」——语义一致且更接近官方口径，零代码改动兼容。
- 省略阈值（360dp 屏）：选秀姓名 ≤8 字等宽、球队榜队名 ≤4 字、左栏分类 ≤6 字；超限仍 Ellipsis。
- 技术统计组单列列头（场均/数值）无「/」→ 走 40dp 普通宽不受影响。
- 回退：逐项 revert（017b389/b380822/de21aef/59892bd/37eba58）。
