# Agent Note: 黄色玻璃导航与原生阅读界面

Status: implemented

## Problem

酷DO 需要保留酷安参考图的悬浮控件和阅读密度，黄色主题还必须保证浅色背景上的文字可读性。长列表滚动时玻璃应采样真实内容，而不是静态贴图。

用户进一步指出底部标签仍使用深琥珀色、静止选中背景为黄色，拖动胶囊被底栏裁切，材质更像模糊而非透明玻璃。现有胶囊只采样页面背景且画在图标下面，不能折射经过的发布按钮；底栏与胶囊共用模糊参数也损失中心清晰度。修正范围为底部导航，文字阅读区域仍使用原来的主题语义色。

加宽镜片后，用户进一步确认酷安从静止进入运动时整条导航放大；后续截图澄清，中心图标和文字仍保持放大，压缩主要集中在弧面边缘，镜片只略高于放大后的底栏。仅改变镜片布局尺寸不能产生整栏抬升，整体反向缩放采样也会错误地抵消中心放大；静止镜片的残留高光会让交叠边缘多出白圈。

## Decision

当前底部导航和详情操作栏直接采用[Backdrop 官方示例](../architecture/2026-10-07-backdrop-demo-navigation.md)的 LiquidBottomTabs 与 Surface Liquid Button。旧 Modifier.glass 已移除。本篇保留主题、原生阅读、网络边界，以及被替代的自绘导航理由和历史验证；当前玻璃参数与验证以新篇为准。

### 被替代的自绘玻璃决策

ui/theme 定义 #FFB003 品牌黄与深琥珀色文本；底部导航高亮图标和文字直接使用 LogoYellow，不读取浅色主题的深琥珀 primary。ui/components/Glass.kt 基于 Backdrop LayerBackdrop 采样底层内容，导航和帖子操作栏作为独立前景层。API 33+ 使用 lens；API 31–32 只模糊，API 26–30 使用半透明表面。选中胶囊用弹簧动画，中心发布入口使用实色黄色。

底栏表面与移动镜片分开渲染。底栏采样页面，使用 3dp 模糊、10 / 16dp 边缘折射和 38% 表面色；静止选中底色为浅色下 10% 黑、深色下 10% 白。第二个 LayerBackdrop 记录底栏表面和图标，前景镜片使用页面与底栏的 CombinedBackdrop，能在拖过发布按钮时折射其轮廓。镜片不进入自己的采样源，外层容器不裁切，只有底栏表面裁切自身。

运动镜片中心不增加 blur，使用 10 / 14dp lens、深度效果、轻微色散、定向高光和内外阴影。运动强度与抬升由 140ms 动画控制；静止灰底随运动淡出，镜片静止时关闭折射并平滑收回，避免文字被持续扭曲。兼容材质不执行 AGSL，API 31–32 的运动镜片最多使用 2dp 模糊。此前帖子操作栏使用独立的 glass 材质参数。

整栏表面、图标和文字使用同一运动进度从 1 放大到 1.04；采样层记录放大后的真实前景，完整液态模式在镜片光学中心将采样从 1 放大到 1.15，叠加整栏后中心内容约为静止尺寸的 1.196 倍，再在距离边缘 10dp 的弧面区域折射。中心图标和文字继续放大，边缘产生局部压缩与色散；兼容模式不增加这项光学放大。参考慢拖帧中同一数字图标运动 / 静止宽度约为 30 / 25px，仅用于校准可见比例，不推定酷安内部参数。手势在固定坐标容器接收，预选与松手目标换算回底栏坐标，镜片位置换算到放大后的可见位置，避免触点和吸附格错位。静止时镜片高光、阴影和光学放大均归零或恒等变换，避免残留白边。整栏缩放需要给两端镜片留足窗口边距，实际比例以同机慢拖和像素检查为准。

拖动时选中胶囊跟随手指，释放后吸附到标签；穿过中心发布按钮不触发发布。位置状态在布局阶段读取，避免每帧重新组合。

真机与酷安对比后，底部导航采用 56dp 高、22dp 图标和 10sp 标签；中央按钮为 44×34dp 横向胶囊。选中镜片静止为 48dp 高，运动时增至 64dp，宽度从格宽减 8dp 增至格宽加 28dp。RMX2202 上运动镜片约 92×64dp，放大后的底栏高 58.24dp，镜片上下各凸出约 2.9dp，呈扁胶囊比例。中心位置保持跟随手指，尺寸变化不改变触控容器布局。整栏距两侧和底部 20dp，保留至少 48dp 的标签触控高度。

### 继续适用的主题与阅读边界

主题根节点用 Material Surface 提供背景和默认前景色，避免只配置 colorScheme 后，普通 Text / Icon 在深色页面仍继承黑色。真机文字布局测试先复现这一缺陷，再检查实际默认文字的亮度。

原生卡片提供作者、分类、标签和回复统计；空状态和网络错误提供明确操作入口。

列表标题为 16sp / 24sp，摘要为 14sp / 22sp，作者与时间保留 15sp 和 12sp；卡片内边距为 12dp，内容间距为 10dp。详情标题为 22sp / 28sp，长文正文为 16sp / 32sp，工具栏标题为 18sp。摘要与正文分别控制密度，避免全局缩字影响长文可读性。首页列表边距和卡片间距为 8dp，顶部标签为 19 / 16sp、普通字号最小40dp，搜索框最小32dp；介绍区和快捷入口已删除，搜索折叠与标签吸顶见[首页标签](2026-10-08-home-tabs-and-collapse.md)。详情内边距为 16dp，底部操作胶囊为最小 48dp。玻璃选中弹簧为 spring(0.9, 650)，底栏按压反馈为 100ms；帖子进入 / 返回使用 280 / 220ms 淡变和轻微缩放。测量依据和动作决定见[酷安密度与过渡对照](2026-10-07-coolapk-density-and-motion.md)。

FeedScreen 按社区筛选展示原生卡片，FeedViewModel 取消过时请求，分页去重，保留分页重试入口。SearchViewModel 保存查询和分页，取消旧查询防止结果覆盖。

分类元数据请求与话题加载结果隔离；分类返回 429 不能把成功的话题列表改为失败。FeedViewModelTest 使用模拟服务先返回话题再返回分类限流，复现并验证这一边界。

RichContent 使用 Jsoup 解析 cooked HTML，输出可选择文本、可点击链接、横向代码块、引用和图片；链接只接受 HTTPS。[行内表情](../bug-fix/2026-10-09-inline-emoji-images.md)保留站点图片并随字号缩放。TopicViewModel 基于 post_stream id 加载缺失楼层，回应和收藏成功后更新该楼层，进行中的操作锁住同一楼层。[详情作者与回应](2026-10-09-topic-author-and-responses.md)负责固定楼主栏、关注、服务端回应状态和分页并发合并。正文图片按[真实比例](../bug-fix/2026-10-09-article-image-layout.md)布局；列表、主帖及各条评论使用[分组相册](2026-10-09-image-gallery-and-transitions.md)，在同窗口全屏覆盖层缩放、滑动浏览，并[缩回当前图片](2026-10-09-image-origin-animation.md)。

## Alternatives considered

- 单纯半透明白色：成本低且兼容所有设备，但无法满足参考图的动态折射；作为系统降级模式保留。
- 整栏与镜片共用 blur / lens 参数：组件封装最少、模糊可掩盖底层杂乱内容，但镜片中心和边缘都变软，图标也没有进入折射源；分离表面与前景镜片，镜片中心保留清晰度。
- 只调高原来的 lens 强度：无需增加图层即可放大背景扭曲，但原镜片画在图标下方，发布按钮仍无法被折射，底栏的裁切也仍然阻止镜片凸出；增加有边界的前景采样层。
- 只继续扩大镜片外形：修改最少且能校正胶囊比例，但底栏和标签不会随抬升放大；统一整栏变换，沿用现有前景采样层，不复制第二套标签。
- 对镜片采样整体反向缩放：能抵消整栏放大，让镜片中心接近静止尺寸，但用户后续截图确认中心文字和图标仍然放大，只有弧面边缘局部压缩；中心保留并加强放大，局部压缩交给边缘折射。
- 使用黄色选中遮罩：选中区域明确且延续品牌色，但用户要求与酷安相同的中性透明灰，底色发黄也掩盖玻璃后的颜色；品牌黄用于高亮图标、文字和发布按钮。
- 每篇正文使用 WebView：Discourse 插件兼容性更好，但列表嵌套滚动、内存和原生文字选择体验更复杂；首版使用原生块渲染，复杂媒体提供浏览器入口。

## Consequences

[完整引用](../bug-fix/2026-10-10-discourse-quotes.md)保留作者小头像、正文分组、折叠及原帖跳转，标题头像不进入正文图片和相册。

视觉、网络和正文解析相互隔离，可以分别校验。玻璃帧率需要真机验证。复杂交互插件、数学公式和音视频当前通过外部浏览器阅读，基础文本、代码和图片在原生页面内完成。

前景采样会增加一个图层和一次镜片绘制，镜片静止时不启用折射。高亮颜色按用户要求采用品牌黄，导航与正文的颜色职责分离。色散强度与折射边缘仍以真机实际图像为准，录屏不能证明稳定帧率或精确还原酷安私有参数。

整栏视觉尺寸与输入坐标需要显式换算，镜片经过标签时边缘仍会短暂扭曲。几何回归负责触点、尺寸和取消复位，完整根画面的像素检查负责中心放大；只读取标签布局尺寸不能证明前景镜片中的实际图像比例。

## Verification

集中检查浅深色主题、玻璃背景滚动、字号放大、列表去重、首帖与后续楼层、HTML 链接与代码块，以及 API 26 / 31 / 33 的材质选择分支。

本轮先在纯白背景的真机测试夹具中读取标签 TextLayoutResult、图标像素与选中区域的色偏，再比较拖动胶囊和标签的实际高度；视觉折射另用同机酷安与酷DO慢拖录屏检查，不用静态 blur / lens 参数断言替代实际图像。

RMX2202 / Android 13 上最初三个测试均先失败：高亮文字为 #805600、选中区域呈 #FFEFCD 黄底、拖动高度为 48dp / 标签 56dp，输出为 artifacts/navigation-material-repro.txt。本轮再先复现整栏不放大（外部图标 44→44px，navigation-scale-repro.txt）和整体反向采样导致镜片中心不放大（48→48px，navigation-center-repro.txt）。当前几何测试读取变换后的 boundsInRoot，像素测试读取完整 Compose 根画面，使前景镜片进入测量结果。

最终完整 12 项 Compose 测试通过，耗时 21.31 秒，输出为 artifacts/navigation-scale-instrumentation.txt，覆盖整栏放大和取消复位、镜片仅略高于放大后的底栏、镜片中心与外部图标均比静止时更大，以及松手位置连续、取消吸附、拖过发布入口不误触和双高亮。Debug APK、测试 APK 和 Lint 通过（0 errors / 26 warnings）。navigation-scale-resting.png / navigation-scale-center.png / navigation-scale-before-after.png、navigation-raised-lens.png 和 navigation-material-dark-large.png 已更新并人工查看，确认中心图标和文字放大、浅色及深色 130% 字号可读，以及镜片仅略凸出底栏。本轮未重跑关闭系统动画的 12 项测试。

复用同机酷安 12 秒参考录屏 navigation-glass-coolapk-motion.mp4，最终酷DO重新录制 navigation-glass-kudo-motion.mp4，并更新 navigation-glass-comparison-00.png 至 -02.png 逐段查看：整栏轻微放大，镜片中心图标和文字放大更明显，运动镜片为扁胶囊且两端未被裁切，能折射发布按钮与经过标签的轮廓，双向拖动后位置、比例与高度平滑收敛；真实首页的静止背景为透明中性灰，图标和文字为品牌黄，镜片静止时没有额外高光白圈。最终普通首页截图为 navigation-glass-home.png，结束留在真实首页。录制设置 60fps 上限，以 10fps 抽帧只验证动作和材质，不推定酷安内部参数或本机稳定帧率；更窄或更宽屏幕的实际比例尚未真机复核。
